# Requisitos Funcionais — Garimpa AI

## RF01 — Visualizar produtos sugeridos

O sistema deve exibir uma lista de produtos sugeridos na tela principal.

Cada produto deve exibir:

- nome;
- categoria;
- imagem;
- nota de oportunidade;
- preço a partir de;
- melhor marketplace sugerido;
- comissão provável;
- botões de ação.

## RF02 — Pesquisar produtos

O sistema deve permitir que o usuário pesquise produtos por nome.

## RF03 — Filtrar produtos

O sistema deve permitir filtros por:

- categoria;
- marketplace;
- nota mínima;
- comissão provável.

## RF04 — Visualizar detalhes do produto

O sistema deve permitir abrir uma tela de detalhes com:

- descrição curta;
- público ideal;
- problema que resolve;
- ponto forte;
- ponto de atenção;
- nota de oportunidade;
- última atualização.

## RF05 — Comparar ofertas entre marketplaces

O sistema deve exibir uma tabela comparando ofertas de um mesmo produto em diferentes marketplaces.

Campos esperados:

- marketplace;
- título da oferta;
- preço;
- avaliação;
- vendidos ou avaliações;
- frete/entrega;
- link original;
- link afiliado;
- comissão provável;
- nota da oferta;
- indicação de melhor opção.

## RF06 — Gerar anúncios

O sistema deve gerar modelos de anúncio para:

- WhatsApp curto;
- WhatsApp completo;
- Instagram;
- Reels;
- Stories;
- Telegram.

## RF07 — Copiar textos e links

O sistema deve permitir copiar:

- anúncio gerado;
- link original;
- link afiliado;
- resumo do produto.

## RF08 — Salvar produtos

O sistema deve permitir que o usuário salve produtos para consultar depois.

## RF09 — Cadastrar produtos manualmente

A área admin deve permitir cadastrar e editar produtos.

## RF10 — Cadastrar ofertas manualmente

A área admin deve permitir cadastrar e editar ofertas vinculadas a produtos.

## RF11 — Exibir avisos obrigatórios

O sistema deve exibir avisos sobre:

- preço sujeito a alteração;
- disponibilidade sujeita a alteração;
- comissão variável;
- ausência de promessa de lucro ou venda garantida.

## RF12 — Página de Privacidade

O sistema deve possuir uma página de Política de Privacidade.

## RF13 — Página de Termos

O sistema deve possuir uma página de Termos de Uso.
