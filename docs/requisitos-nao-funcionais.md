# Requisitos Não Funcionais — Garimpa AI

## RNF01 — Responsividade

O app deve funcionar bem em desktop, tablet e celular.

## RNF02 — Usabilidade

A interface deve ser simples, clara e adequada para usuários iniciantes.

## RNF03 — Performance

As telas principais devem carregar rapidamente, evitando excesso de dados e componentes desnecessários.

## RNF04 — Segurança

O sistema deve proteger dados de usuários, credenciais e chaves de API.

Nenhuma chave secreta deve ser exposta no front-end.

## RNF05 — LGPD

O sistema deve coletar apenas dados necessários para sua finalidade.

Não devem ser coletados dados sensíveis na V1.

## RNF06 — Manutenibilidade

O código deve seguir boas práticas de organização, com componentes reutilizáveis e nomes claros.

## RNF07 — Escalabilidade

A arquitetura deve permitir integração futura com banco de dados, IA e APIs oficiais de marketplaces.

## RNF08 — Confiabilidade

O app deve comunicar claramente que preços, disponibilidade e comissão podem mudar.

## RNF09 — Auditoria básica

Alterações importantes, como cadastro e atualização de produtos, devem ter campos de data de criação e atualização quando houver banco de dados.

## RNF10 — Acessibilidade básica

O app deve usar contraste adequado, botões legíveis e textos compreensíveis.
